# Lawn Care & Landscaping Website

A production-ready Website Core industry module for lawn care, landscape installation,
property maintenance, and outdoor-living businesses.

## Included workflows

- Editable services with categories, audience flags, images, featured state, and ordering.
- Before-and-after projects, maintenance plans, service areas, and seasonal offers.
- Estimate requests with contact consent, server validation, CSRF, rate limiting,
  a honeypot, and up to three private property photos.
- Lead filtering, statuses, internal notes, protected photo review, notification mail,
  dashboard reporting, admin search, and a storage health check.
- Core-owned branding, primary/footer navigation, social links, copyright, media,
  authentication, and permissions.

## Design family

All themes use the same Core-owned logo, menus, content, media, and business settings.
Bold Outdoors is the default.

1. **Bold Outdoors** — charcoal, lime, and oversized display type.
2. **Estate Green** — forest green, ivory, and restrained brass.
3. **Neighborhood Lawn** — friendly green, white, and rounded surfaces.
4. **Earth & Stone** — warm neutral, editorial landscape-studio treatment.

Each theme is distributed as a separate Core theme ZIP in `theme-packages/releases/`.
Changing themes affects presentation only.

## Compatibility and installation

Version **1.0.0** requires Website Core **2.0.7 or newer within the 2.x line** and
Module API 1. Install `releases/industry-landscaping-1.0.0.zip` through Core's package
installer. Install any desired theme ZIP separately through Appearance, then activate
it there. The module seeds demonstration content only when its service table is empty;
subsequent boots and upgrades preserve saved content and Core customization.

Replace demonstration business copy, service areas, project details, and images before
a customer launch.
