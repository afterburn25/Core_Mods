# Lawn Care & Landscaping Website

An AllWebPro industry module for lawn care, landscape installation, property
maintenance, and outdoor-living businesses.

## Design family

The module uses one Core-owned default logo and one editable navigation/content
model across four visual themes:

1. **Bold Outdoors** — default; charcoal, lime, oversized type.
2. **Estate Green** — forest green, ivory, restrained brass.
3. **Neighborhood Lawn** — friendly green, white, soft rounded surfaces.
4. **Earth & Stone** — warm neutral editorial landscape-studio treatment.

Theme changes affect presentation only. Core retains the live logo, navigation,
footer, social links, copyright, pages, media, and business content.

## Current foundation

- Public routes and responsive navigation are registered.
- Services use an editable nested dropdown owned by Core after first import.
- A single transparent leaf mark seeds Core Media once.
- Bold Outdoors is the fallback/default presentation.
- Three alternate theme packages are defined for Core Appearance switching.

Requires Website Core 2.0.7 or newer within the 2.x line.
